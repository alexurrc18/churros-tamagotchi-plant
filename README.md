Inspired by the "Starboy" accessory created by lilguy, Churros is an embedded systems project developed for our university course. Instead of traditional numeric readouts or app notifications, Churros brings a plant to life by expressing its needs like a human character.

## Features
* **Microcontroller**: Built around the ESP32-S3 board for reliable wireless connectivity and processing power.
* **Sensor Integration**: Monitors real-time environmental parameters (such as soil moisture, temperature, and light).
* **Expressive UI**: Utilizes a connected display to render animated facial expressions, visually communicating the plant's current "mood" and needs based on sensor feedback.
